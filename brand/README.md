# EaglesEye Brand Assets

Mark: **"Cyber Raptor"** — faceted eagle head with a robotic reticle eye.
Chosen 06 Aug 2026 (concept round 2, variant A).

## Files

| File | Use |
|---|---|
| `eagleseye-icon.svg` | Primary mark, light backgrounds |
| `eagleseye-icon-dark.svg` | Mark for dark backgrounds (light head) |

## Rules

- The reticle eye is the brand: never remove the crosshair ticks at full size.
- At 32 px and below, simplify: solid head silhouette + outer ring + centre dot only (drop facets, dashed ring and ticks).
- Wordmark: "Eagles" navy, "Eye" cyan. Tagline: "WE SEE YOU — WHEREVER YOU ARE".
- Wordmark typography is currently Segoe UI as a placeholder; choose a licensed brand typeface before public launch. Arabic version of the wordmark still to be designed.
- Minimum clear space around the mark: the height of the beak facet.
